## 1. Cek pra-rilis di produksi (baca-saja)

Aturan baru F-5 **langsung berlaku** saat kode terunggah: Cash Advance hanya untuk beneficiary INTERNAL ber-PIC
dengan Token angka > 0. Jalankan di phpMyAdmin produksi **sebelum** upload; query ini hanya membaca.

```sql
-- a) Beneficiary INTERNAL yang akan TERBLOKIR untuk Cash Advance
SELECT b.id, b.nickname, b.complete_name, p.pic AS pic, p.token
FROM beneficiaries b
LEFT JOIN master_pics p ON p.id = b.pic_id
WHERE b.category = 'INTERNAL'
  AND (b.pic_id IS NULL OR p.id IS NULL OR p.token IS NULL OR TRIM(p.token) = ''
       OR TRIM(p.token) NOT REGEXP '^[0-9]+$' OR CAST(TRIM(p.token) AS UNSIGNED) < 1)
ORDER BY b.nickname;
```

```sql
-- b) Draft / pengajuan Cash Advance yang belum disubmit dan akan tertahan saat simpan/submit
SELECT br.id, br.code, br.status, b.nickname AS beneficiary, b.category, p.pic AS pic, p.token
FROM budget_request br
JOIN request_type rt ON rt.id = br.type_id
LEFT JOIN beneficiaries b ON b.id = br.beneficiary_id
LEFT JOIN master_pics p ON p.id = b.pic_id
WHERE LOWER(TRIM(rt.name)) IN ('cash advance', 'cash-advance', 'cashadvance')
  AND br.status = 'DRAFT'
  AND br.deleted_at IS NULL
  AND (b.id IS NULL OR b.category <> 'INTERNAL' OR b.pic_id IS NULL OR p.id IS NULL
       OR p.token IS NULL OR TRIM(p.token) NOT REGEXP '^[0-9]+$' OR CAST(TRIM(p.token) AS UNSIGNED) < 1)
ORDER BY br.id;
```

```sql
-- c) Nama role (cek huruf besar / spasi — relevan untuk cutover nanti) & jumlah user
SELECT r.id, CONCAT('[', r.name, ']') AS nama_role, r.status, COUNT(u.id) AS total_user,
       SUM(u.status = 'ACTIVE') AS user_aktif
FROM roles r LEFT JOIN users u ON u.role_id = r.id
GROUP BY r.id, r.name, r.status ORDER BY r.name;
```

Tindak lanjut: isi Token di **Master PIC** untuk PIC yang memang boleh mengajukan CA (angka = batas jumlah CA
berjalan). Bila hasil (a)/(b) besar dan belum siap dilengkapi, **tunda rilis** — F-5 tidak punya saklar.

## 3. Urutan deploy

1. Mode maintenance (opsional, disarankan): `php artisan down`.
2. Tarik/unggah kode branch `update/v3.3.2` (semua commit di §header).
3. `php artisan migrate` — menjalankan **hanya** `2026_11_07_000500` s/d `000900` (semua additive; dua di antaranya
   mengisi tabel baru dari config).
4. `php artisan optimize:clear` (config, route, view, cache). Ada route baru `security.*` dan `role.store`.
5. `php artisan up`.
6. Periksa log `storage/logs/laravel.log`: harus ada `Seed role_permissions (parity) selesai` dan
   `Seed role_data_scopes (parity) selesai`. Bila ada peringatan "DILEWATI" atau "0 baris": jalankan
   `php artisan security:sync-permissions` (dry-run, hanya melapor) lalu `--apply`.
7. **Belum** menyalakan mode shadow pada hari rilis — lihat §5.

`.env` tidak perlu diubah untuk rilis ini (`SECURITY_PERMISSION_MODE` bawaan `off`).
